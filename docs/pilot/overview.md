# eira Pilot — Overview

## Status

Early working document. The pilot will be documented as it develops; new documents and directories should be added when a concrete need emerges rather than designing the full documentation structure in advance.

## Overview

The eira pilot is the first real-world implementation of eira. It is intended to connect the technical system with actual users, devices, infrastructure, learning and practical work.

The pilot should be treated as an experiment: build a useful minimum system, observe how people use it, document what works and what fails, and let those observations shape the next iteration of eira.

## Initial documentation

- `purpose.md` — why the pilot exists and what we want to learn
- `finance.md` — financing model and financial assumptions
- `budget.md` — concrete pilot costs and scenarios
- `architecture.md` — technical and physical architecture of the pilot

This structure is deliberately small. Add more documentation when the work itself creates the need.
