# eira Pilot — Purpose

## Purpose

The purpose of the pilot is to test eira in a real environment with real people rather than designing the system only from assumptions.

The pilot should help answer questions such as:

- What do people actually use eira for?
- Which workspaces and tools create practical value?
- What hardware is sufficient?
- How much connectivity and compute are required?
- What should work locally when connectivity is poor?
- How should eira support learning without replacing the user's own agency?
- Can eira make unfamiliar digital tools easier to learn and use?
- What does the system cost to operate per user?
- Which parts of the model can be maintained locally over time?

## Principle

The pilot is not intended to prove that a finished design is correct. It exists to discover what the design should become.

Build, observe, measure, learn and iterate.
