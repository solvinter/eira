# NaCCA

This directory contains official curriculum documents published by the National Council for Curriculum and Assessment (NaCCA), Ghana.

## Purpose

These documents constitute the primary educational knowledge source for Eira.

Documents are organised by subject to support curriculum-aligned retrieval using Retrieval-Augmented Generation (RAG).

## Current Subjects

- Mathematics
- English
- Science
- Computing
- Social Studies

Additional subjects will be added as the project expands.
