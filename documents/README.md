# Knowledge Base

This directory contains the primary knowledge sources used by Eira.

The original documents are stored here in their native format (PDF, text, etc.).

These files are never modified by Eira.

Instead, they are processed into chunks, embedded using an embedding model, and indexed in Qdrant for semantic retrieval.

## Structure

- nacca/        Official curriculum documents
- textbooks/    Approved textbooks
- agriculture/  Agricultural knowledge
- health/       Health-related educational material
